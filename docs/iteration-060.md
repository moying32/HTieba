# 0.6.0 分层卡片搜索与发帖

2026-11-13，versionCode 17。将用户选定的0.5.8“分层卡片”交互稿落实为原生Compose界面。

## 实现与设计取舍

| Before | After | Why |
| --- | --- | --- |
| 搜索框和操作挤在单行 | 独立玻璃输入层；窄宽度下搜索动作换行 | 放大界面时仍保留输入和清除空间 |
| 历史与热榜平铺 | 小字历史标签卡、统一热榜分组 | 区分本机记录与百度榜单，改善信息层级 |
| 分类仅搜索后可选 | 搜索前可选帖子/吧/用户 | 输入和历史/热榜使用当前真实分类，无演示综合入口 |
| 发帖连续多个轮廓输入框 | 账号与发布吧卡、标题正文共享编辑卡、图片卡 | 建立编辑主次，连续写正文 |
| 发送和异常混在编辑区 | 独立反馈卡和预览发布入口 | 加载、错误及结果未确认状态清晰可达 |

搜索保留百度接口热榜与服务端排序、历史前4条/展开更早/清空确认、帖子链接/ID直达、吧直达、三类结果、下拉刷新、加载、空态、失败重试和分页。热榜行保留LazyColumn按需组合，不为每行采样模糊或播放入场。

发帖保留真实账号头像与昵称、关注吧快捷选择（显示“吧”后缀）、手动输入吧名、标题90字/正文10000字上限、本机草稿、最多9张图与持久读取权限、发送锁定、上传进度、错误与未确认结果核对。点击“预览并发布”后仍需在对话框明确确认；未接入的视频/语音/投票不添加空按钮。

分层卡片使用当前主题surface/onSurface及细描边，搜索输入复用现有GlassPanel。现有液态玻璃折射、导航透镜与页面动画不变。标题/正文/搜索/选吧维持至少48dp物理触控高度；界面、字体倍率独立，支持50–150%。

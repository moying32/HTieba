# 0.8.3 GitHub Issues 迭代

2026-11-27。基线是 0.8.2，Android 版本码由 45 升至 46。本版处理 GitHub 的三个开放 Issue。

- [#1 一键签到](https://github.com/moying32/HTieba/issues/1)：登录后启动预读，手动刷新「管理我的吧」时重新读取，只更新签到状态。点击「一键签到」后优先走贴吧的批量接口，时段、等级等条件由服务端判定。按关注吧列表回读结果，只对明确未签到的吧补签。安全验证和无法确认的批量结果会暂停补签。继续和仅重试失败都先读取新状态。
- [#2 推荐页信息密度](https://github.com/moying32/HTieba/issues/2)：推荐卡片缩小头像、提高正文对比度，默认显示四行正文，图片和视频封面占卡片内容宽度 75%。「设置 → 外观与主题」可选 2–6 行和 50%、75%、100% 宽度，保存后立即应用。
- [#3 官方客户端评论入口](https://github.com/moying32/HTieba/issues/3)：评论编辑面板新增「去百度贴吧评论」。使用官方包名和原帖的 `tid` 打开百度贴吧客户端。无法跳转时可打开同一篇网页原帖。返回氢贴吧后可以继续使用原草稿。

批量签到使用现有本地协议参考中的 `/c/c/forum/msign` HTTPS hybrid 表单，完整关注吧列表的状态缺失时，用 `/c/f/forum/forumGuide` 按吧 ID 补充。对照本地官方 22.13.1.1 APK 的路由声明与调用位置，帖子入口为 `com.baidu.tieba://unidispatch/pb?tid=…`。

初次交付时暂缓实机验收。后续实机结果见下文。

本地验证通过 295 项 JUnit 测试。发布 Lint 检查为 0 错误、64 警告、2 提示。最终 APK 通过发布关键 Lint、R8 和 APK v2 签名验证，证书与 0.8.2 相同。安装包内的包名为 `dev.hydrogen.tieba`，版本为 `0.8.3`，版本码为 `46`。

安装包为 `apks/HTieBa-0.8.3.apk`，SHA-256 为 `fd0774d8abeedba7ca04b4a6f3cb971ea4e5898cccd23724e7725863bc3bef6a`。本地日志为 `.tools/checks/083-check.log` 与 `.tools/checks/083-release.log`。

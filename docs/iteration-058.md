# 0.5.8 阅读布局、主题与个人页

2026-11-13，versionCode 16。针对用户截图修复，并提供搜索/发帖输入的独立设计稿。

## 实现范围

| 问题 | 修改 |
| --- | --- |
| 信息流图片覆盖标题或元信息 | 图片行先按可用宽度和数量计算统一高度，再给图片明确边界；移除最大高度和宽高比相互冲突的测量约束。视频封面同样保持单一宽高比约束。 |
| 深色文字与底色相同 | 根主题提供随色板变化的默认文字颜色；玻璃和个人背景遮罩增加对亮暗照片的保护。主题强调色、提示/错误色仍保留语义。 |
| 图片工具栏常驻 | 进入显示、单击隐藏、再次单击显示；保留双击放大、双指缩放、左右翻页、系统返回和无障碍替代动作。 |
| 我的页底栏与背景 | 个人页根页面底栏常驻；右上背景入口选择本机图片，按账号保存到应用私有目录，支持恢复贴吧官方背景。仅改变本机外观，不上传账号背景。 |
| 界面倍率 | 50–150%连续浮点滑条，常用50/75/100/125/150%；预览后应用，保留实际触控区域。字号仍独立。 |
| 账号页信息不足 | 头像、昵称、用户ID、性别、吧龄、IP属地、简介、关注/粉丝/主题帖/回帖；未返回的字段明确标记。提供原有资料编辑入口，不展示认证凭据。 |
| 气泡不够圆 | 加大玻璃外框、菜单外框/内层、跳转模块和显式局部气泡圆角，保留圆形和胶囊轮廓。 |
| 表情放大模糊 | 优先接口原资源，原尺寸解码、高质量采样；内联尺寸由1.35em收至1.12em。经典素材仍采用已验证的官方资源，部分只有30×30像素，不宣称恢复不存在的高清细节。 |
| 主导航页面衔接 | 按首页/逛吧/消息/我的次序左右移动；200ms短转场，最多5dp页面模糊和低强度径向渐晕，液态玻璃底栏及透镜手势物理保留。减弱动效/系统关闭动画直接切换；Android12以下无RenderEffect模糊。 |

## 输入框设计稿

`input-designs.html`提供“紧凑胶囊”“分层卡片”“底部浮动输入”三种方案，各自有搜索/发帖页和浅深色。支持文字输入、清空、搜索范围、示例历史、草稿与本地发布反馈；全部为设计演示，无账号网络写入。选择方案后再实装原生输入布局。

交互验证：三方案×浅深色×桌面/390px手机宽度，共12组；另检查键盘切换不拦截输入、URL选择持久化与无横向溢出。日志和截图见`.tools/checks/v058-input-results.json`及同前缀PNG。

# 0.7.9：GitHub应用内更新

2026-11-21。新增设置检查更新、冷启动后台检查、新版提示、按版本跳过、应用内下载与系统确认安装，沿用现有原生Compose设置及按钮。完整贴吧客户端的发布、互动、消息、关系和账号目标继续保留。

## 行为与设计

| Before | After | Why |
| --- | --- | --- |
| 设置没有更新入口 | 设置首页和关于页进入软件更新，可手动检查 | 用户可直接确认当前版、GitHub版本及错误原因 |
| 新版只能另找安装包 | 启动后台检查；新版弹窗显示说明和大小，用户下载后确认安装 | 减少寻找安装包的步骤，安装意愿由用户决定 |
| 无版本提醒偏好 | 稍后提醒、仅跳过当前版本；手动仍可查看 | 不反复打扰，也不屏蔽未来更高版本 |
| 无更新网络状态 | 检查中、下载进度、取消、失败重试、安装校验和授权反馈 | 操作及时可见；启动网络失败不打断阅读 |
| 关于页进入更新后缺少来源返回 | 软件更新保留设置首页/关于页来源，系统与页内返回一致 | 返回原入口，过渡方向遵循层级 |

更新源为 `moying32/HTieba` 公开Releases，包含预发布；按SemVer比较，不降级。使用独立无账号凭据HTTPS客户端、ETag缓存、私有文件和FileProvider。下载校验长度/可用摘要，安装前复验同包名、版本名称、递增versionCode、同签名和系统兼容性。取消与重试隔离迟到回调，无法打开系统授权页时给出可见错误。

入口与发布规则见[应用内更新说明](app-updates.md)。首次必须手动安装含更新功能的新包；后续发布仍需上传同证书、正确版本号的Release APK附件。本次不提交、推送或发布GitHub Release。

# 0.5.6 消息修复、分级设置与表情显示

本轮按用户要求只修改代码、运行电脑检查并生成安装包，不使用 ADB、不安装、不操作手机、不发送私信或群消息。

## 已实现

- 点赞通知按接口的 `agreeer`、`thread_info`、`post_info` 嵌套结构解析昵称、头像、帖子和评论；保留头像 URL 查询参数及通知分页游标。兼容回复和 @ 通知的旧字段，缺失身份仍用占位，不编造账号。
- 回复通知的动作标题改为“回复我：”；只移除正文开头针对当前账号或“我”的重复回复前缀，其他人的回复前缀和引用保留。
- 回复通知、我的评论定位先用 `pid` 响应确定页码，再按 `pn` 获取完整分页。主楼正文保留，目标所在页保留前后楼层，可回到原帖开头、补读此前楼层及继续向后分页。接口定位失败仍打开原帖；找不到目标时明确提示。
- 楼中楼定位先找到父楼，再逐页读取子回复并滚到目标，显示定位标记。一次定位最多读取30页，避免无限请求；未找到时说明结果，可继续加载。请求可被返回操作取消。
- 所有四处下拉菜单（帖子卡片、帖子详情、评论、视频倍速）复用22dp圆角外框、14dp内部气泡及统一间距，保留48dp真实触控和原生关闭行为。
- 帖子详情右上角的官方原帖按钮移除。加载失败、评论结果不确定和视频错误时的兜底入口继续承担错误恢复。
- 设置首页改为六类：外观与主题、字体与界面、阅读与媒体、交互与动效、账号、关于。主题管理/制作教程、字体选择作为下级页面，返回逐级恢复。全部现有偏好保留，关于版本来自 BuildConfig。
- 贴吧 type=2 表情恢复为正文中的内联图片；经典表情编号使用已匿名验证的百度 CDN，优先使用接口提供的自定义资源（含 meme_info），修正旧静态主机的 HTTPS 资源路径。新增 Coil GIF 解码，Android28及以上使用 AnimatedImageDecoder，旧系统使用 GifDecoder。表情跟随字号，保留无障碍名称、复制文本和失败回退，不加入照片图库。

## 聊天实际范围与剩余缺口

消息页新增明确的私信与吧群入口：

- 私信打开应用内百度官方 HTTPS 私信页面，共享本应用已有 WebView 登录态；页面标题明确为官方网页。匿名访问已确认可到达登录页面，**没有验证登录后的私信列表或发送，不等同于原生私信接入完成**。
- 吧群提供按吧查找、群资料/公告、历史消息和更早消息读取的原生界面，接入 `/c/f/chat/getRoomListByFid`、`/c/f/chat/getChatRoomDetail` 与 `https://pim.baidu.com/rest/3.0/im/fetch_mcast_msg_client`。保留接口错误、失败重试、去重及账号切换清理；不自动加入群聊、不发送已读回执。
- 群消息正文解析官方嵌套JSON，只在服务端确实返回发送者ID时显示该ID及主页入口；未获取昵称或头像时不将占位当成完整身份。非文本消息目前提示类型。
- **原生私信会话/历史/收发、已加入群列表、群聊发送、实时收取、未读同步及群媒体尚未完成。** 已找到的旧私信参考采用 `ws://im.tieba.baidu.com:8000` 且登录帧含BDUSS；未启用该明文凭据通道、未关闭TLS校验。当前找到的群发送协议为BLCP，安全传输及完整消息协议仍待核对。
- 群聊路径与字段依据公开参考独立实现，电脑测试使用固定样本；实际账号可用性、群权限及会话表现均未实机验收。不能把新增入口和读取代码表述为完整聊天功能。

# 0.5.2 个人页背景与关系胶囊

2026-11-12，用户要求将关注/粉丝移到头像右侧，增加可点击液态玻璃胶囊，个人主页背景向白色渐变衔接。Kotlin / Compose原生实现，沿用emil-design-eng和apple-design的层级、材质、反馈与可读性原则。

| Before | After | Why |
| --- | --- | --- |
| 关注/粉丝普通文字在昵称下面 | 头像右侧两个独立液态玻璃胶囊，数值与标签上下分层 | 关联身份和关系，入口可见且可点 |
| 个人页只用主题画布 | 读取贴吧资料`user.bg_pic`，在界面后方显示主页背景并向底面渐变 | 保留账号原有装扮，与白色内容自然衔接 |
| 背景缺失 | 当前主题柔和渐变占位，加载失败同样回退 | 不虚构账号背景，不增加重复转圈 |
| 新控件可能采样到自身 | 个人页单独记录只含背景的GraphicsLayer，胶囊位于该层之外 | 复用原折射/模糊，避免递归采样 |

头像72dp，右侧胶囊平分剩余宽度，最小64dp高度，随字号自然增高；按压沿用现有反馈，关闭玻璃为实色，减弱动效不缩放。点击分别打开原生关注/粉丝列表，只读百度数据，不改变关注关系。保留单一设置入口、内容与管理功能行。

协议根据本地原版22.13.1.1的`tbclient.User.bg_pic`字段确认；公开资料只读查询确认本账号12.35.1.0兼容接口确有`bg_pic`，22.13.1.1请求返回空值，因此沿用原有兼容资料接口，不改变账号认证或其他参数。仅接受有效HTTP(S)图片地址，不从头像、广告banner或主页装扮跳转链接猜背景。

浅色背景在下方淡出至主题surface（映间为白色），深色/自制主题淡出至其对应surface，避免深色突变白色。主页背景在个人页后方固定，内容仍可滚动；未接入背景编辑、动态装扮或上传。

电脑与真机结果见[开发状态](development-status.md)及[真机验证](device-validation.md)。

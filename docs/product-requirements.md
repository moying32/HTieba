## 参考 X 的方向

用户要求参考 X 的模式。当前将其落实为信息架构和使用效率上的参考；最终视觉与导航通过原型确定。

- 首页以内容流为中心，推荐与关注分开，减少欢迎文案和大块装饰占用的首屏空间。
- 使用紧凑的作者、正文、媒体和互动栏层级，让一屏呈现更多真实讨论；高频操作保持直接。
- 搜索、发布、回复和消息有稳定入口；发布入口能够进入完整编辑流程，支持草稿和媒体。
- 个人主页、关注关系、收藏和设置形成清晰路径，消息能回到对应帖子与楼层。
- 保留贴吧业务结构：吧是社区，帖子保留标题，评论保留楼层与楼中楼；关注吧和关注用户分别管理。

2026-11-11 用户通过《要求补充.md》明确导航为五个入口：**刷帖、逛吧、发帖、消息、我的**，其中发帖使用加号按钮，整体保留悬浮胶囊形式；浏览内容时收起，反向滚动时恢复。此要求取代此前四个主入口加独立发布按钮的提案。

以上方向来自用户指定的 X 参考和本项目的实现提案；详细视觉与手势仍需通过原型确定。

## 验收规则

- 每项能力区分未实现、已接入、只读验证、真实写操作验证和真机通过；构建通过不能代替功能通过。
- 以真实用户任务验收，例如搜索一个吧 → 关注 → 发图文帖 → 收到回复 → 进入对应楼层 → 管理自己的内容。
- 广告过滤覆盖真实列表与详情，保留普通用户内容；不能仅因含有商业词语就删除普通讨论。
- 不为验收随机发布、点赞或关注。真实写操作使用用户明确允许的目标和内容；2026-11-11 本轮用户选定只验收阅读与界面。
- 界面实施继续遵守 `design-guidelines.md`，以阅读效率和操作效率衡量样式取舍；当前绿色与玻璃材质属于阶段视觉，后续根据原型调整。

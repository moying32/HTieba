# 氢贴吧 0.7.10

2026-11-21，Asia/Shanghai。将已完成限定实机验收的更新限流修复纳入0.7.10，内部版本号35；用户授权覆盖安装、同步GitHub main及创建Release，并删除旧的9.5.0测试Release及其遗留标签。

## 本版变更

- 更新检查优先读取GitHub官方公开Releases Atom订阅、附件及发布页面，原REST API为备用，减少对匿名API额度的依赖。
- 继续支持每次冷启动自动检查、设置及关于页手动检查、跳过当前版本、应用内下载/取消和系统确认安装。
- 公开页路径获取附件可用SHA256及HEAD精确字节长度；下载及安装前保留包名、版本、签名、minSdk等校验，不内置token或第三方下载代理。
- 将版本名从测试修复包0.7.9+updatefix.1改为0.7.10，versionCode从33升至35，高于原9.5.0空壳的34，支持同证书保留数据覆盖恢复客户端。
- 本次main同步包含此前0.7.7–0.7.9的反馈修复、更新功能和对应测试；那些改动在本机已存在，参见各版本历史记录。

## 安装与边界

在GitHub Releases下载`HTieBa-0.7.10.apk`。最低Android8.0/API26，目标API36，包名`dev.hydrogen.tieba`。沿用现有开发测试证书，非正式签名迁移；同签名且版本号较低的已有安装可保留数据覆盖升级。

项目仍是开发版；消息与群聊、真实写操作、富媒体发布及后台通知等能力继续按[功能台账](feature-status.md)推进。旧私信认证链路仍有未使用HTTPS的已知限制。GitHub公开页和备用API可能同时不可达，公开网页结构变化也可能影响检查；失败时保留可重试错误。

本版发布时项目自身采用MIT（历史状态；当前许可见[授权说明](licensing.md)），第三方组件维持各自授权；Release提供第三方声明包和SHA256SUMS。本版源码标签对应main发布提交，不将开发签名私钥、账号数据、设备截图或本机环境配置纳入源码。

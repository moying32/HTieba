# 0.5.4 评论与图片日常流程

2026-11-12。用户授权继续开发并按已有设计推进。本轮承接评论/楼中楼交互稿，补齐图片连看、保存和正文信息操作；保留0.5.3顶部连续滚动与70–120%无级界面倍率，保留底部导航原有玻璃和手势。

开发中用户追加：所有按钮和页面跳转模块都有气泡背景。采用公共原生控件统一实现：图标为圆形气泡、短文字为胶囊、长菜单/用户/吧/热榜/消息入口为圆角气泡；推荐/关注与搜索分类的未选中项也有底，选中项保留强调色及状态语义。原有填充按钮、图片圆角、主题/字体选择卡、个人页关系胶囊、滑条与底栏继续使用其既有背景。

高频列表中的气泡使用主题色适配的轻渐变和细高光边，不逐项分配离屏采样/模糊；原来的悬浮玻璃继续采样与折射。关闭玻璃时使用实色底；按压水波、加载、禁用、系统返回和至少48dp触控区域继续使用原生语义。仅改变可操作入口的表现，不把普通正文和只读统计变成按钮。

| 修改前 | 修改后 | 原因 |
| --- | --- | --- |
| 评论大卡片、正文/媒体同宽、楼中楼只有入口 | 左头像右正文、紧凑元信息与回复/赞、小配图；接口返回的真实摘要放浅底区域 | 评论信息层级明确，保留所有内容与交互 |
| 楼中楼父评论只有文字截断，打开回复后丢失对话 | 完整父评论、小头像子回复与左细线、玻璃回复栏；关闭回复编辑器回到原对话 | 保留讨论上下文与精确回复对象 |
| 子回复点赞状态默认未赞；正文用户提及只是文字 | 统一解析点赞状态；真实用户ID的提及支持进入主页 | 修复读取正确性和用户导航 |
| 评论未显示属地和准确时间；只能逐段选择复制 | 按接口显示属地；更多菜单可复制整段正文、查看精确时间与回复ID | 便于长文复制和核对讨论信息，不猜测缺失字段 |
| 图片只能逐张打开，无法保存 | 按帖子/单楼图片来源组成图库，左右滑动/按钮翻页；保存接口提供的原图或最清晰可用文件 | 完成多图阅读和保存流程 |
| 保存解码图可能丢失清晰度、动画与文件类型 | 后台流式保存原文件，识别真实图片类型，系统选择保存位置 | 保留原文件字节与GIF动画，失败可重试、取消不写账号 |
| 图标/文字按钮及部分页面入口无常驻底 | 公共气泡控件与圆角入口底，适配主题和禁用状态 | 用户要求所有按钮、跳转模块具有可辨认的背景 |

评论摘要直接使用现有详情响应，不逐楼额外请求。用户提及只在接口给出有效ID时可点击；未知属地不显示占位，信息页明确“贴吧未提供”。精确楼中楼回复仍使用父楼quote_id与目标sub_post_id，草稿按目标隔离，不自动重发。

图库仅包含接口实际返回的图片，保留带签名的独立地址；画质仍只在设置选择，预览不恢复底部常驻教程。原画预览仍有既有4096像素解码上限，但保存为服务端文件原始字节。公开图片请求不转发百度登录Cookie；验证页和错误文本不得保存为图片；流式下载上限80MB。系统保存对话框由用户选择位置，取消或失败清理临时文件。

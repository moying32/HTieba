## 七、开发环境的间接包清单

已审计的本机 Python 工具环境包另存为 [开发工具Python依赖清单.csv](开发工具Python依赖清单.csv)，共 **60 条环境/声明记录**；直接构建清单共 **22 条依赖/插件声明**。记录含名称、版本、元数据中的作者、项目网址、来源环境和证据路径。Python 来源覆盖：

- `.tools/requirements.lock.txt` 与 `.tools/python/Lib/site-packages/*.dist-info/METADATA`：mitmproxy 工具环境及其间接依赖。
- `.tools/promo-python/*.dist-info/METADATA`：宣传片工具环境及其间接依赖。
- 宣传片 `requirements.txt`：直接使用但不一定在该局部目录留下元数据的依赖。

例如 aiohttp、aiohappyeyeballs、aiosignal、attrs、certifi、cryptography、Flask、Jinja2、Werkzeug、h2、wsproto、Tornado、cffi、pyOpenSSL、multidict、yarl 等，属于工具环境依赖。它们不因此成为氢贴吧 Android APK 的依赖；安装元数据也不能证明每个库的代码路径都在本轮执行。

CSV 的网址和作者来自安装元数据，未能取得的字段明确留作“待核实”。不把间接依赖作者与直接参与氢贴吧开发的人混为一谈。

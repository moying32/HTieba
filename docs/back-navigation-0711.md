## 问题与实现

- 原根路由按页面种类的固定深度比较方向。帖子打开吧页面、资料页打开另一资料页等路径不能据此推断前进或返回；旧版真机录屏复现了从吧返回原帖时原帖从右侧进入的错误方向。
- `PageNavigation` 保存实际导航操作及来源、目标、序号。打开与返回分别标记；根页面过渡按该操作决定方向。栏目点击保留既有顺序动效，系统返回首页按返回动作处理。
- 帖子打开时保存来源快照，关闭时恢复对应来源；支持恢复已有帖子、资料、吧及本机列表的既定导航上下文。
- 使用 `PredictiveBackHandler` 获取系统手势进度。左、右边缘分别向拖动方向提供轻微平移与缩放反馈；取消回位且不改变页面，提交只切换一次，不追加第二段页面滑动。按钮或系统返回键仍采用短促的反向过渡。
- 设置子页通过明确父页关系返回；手势完成后保留过渡控制器，使下一次系统或工具栏返回仍连续。聊天的键盘、资料、多选、搜索继续先处理自身返回，无局部状态时交给根手势处理。
- 根路由容器在最简、减弱动效及系统动画开关变化时保持同一内容所有者，避免重建设置页并丢失子页层级。关闭动画或提交手势时使用无过渡策略；设置内部的即时呈现不保留旧页。
- 手势期间若来源路由已经变化，不提交针对旧来源的返回。图片、视频和弹层仍由其既有返回优先级处理。

日期：2026-11-11。原生 Kotlin / Compose，数据仍来自百度贴吧。本文区分代码接入、只读真机验收和真实写入；不会将一个空列表或编译成功当作完整业务通过。

## 本轮设计

依据用户指定的《X式帖子显示.md》采用左侧头像、右侧作者与身份/时间/更多、吧名、标题、摘要、附件、互动统计的层级。附件原始文件后续已不在桌面原路径；六行规格已保存到产品要求文档，不重新推断附件内容。

| Before | After | Why |
| --- | --- | --- |
| 我的页占首屏的装饰背景、三项大菜单和单独的关注吧入口 | 账号资料、关注/粉丝；紧凑四项内容行；下方三项管理行；一处设置 | 简化布局并增加业务入口 |
| 列表头像与正文宽度相互独立 | 左头像，所有帖子内容位于右列；更多菜单容纳云收藏/分享 | 统一附件要求的帖子结构 |
| 吧名仅显示文本 | 吧名进入真实吧页，吧头可展开资料与吧务团队 | 保留社区结构与返回路径 |
| 仅正文大字号开关 | 字体 85–140%、界面 90–120%，分别预览、应用、保存、重置 | 支持阅读密度与系统字号；缩小时保持触控尺寸 |
| 评论列表未接入 | 独立读取账号评论，并展开服务端按帖子分组的多条回复 | 保留每条评论的正文、时间和目标标识 |
| 详情回复数包含主楼 | 仅在详情协议中扣除主楼，列表按各自字段语义处理 | 与原版的评论计数一致 |
| 新帖按钮只跳网页 | 原生选吧、标题正文、图文草稿、选图、预览确认和提交状态 | 建立原生发布流程，真实发布另行验收 |
| 固定界面字体 | 跟随主题、系统默认及三款离线中文字体，样本预览与授权查看 | 满足字体选择并兼容系统缺字回退 |
| 只有内置风格 | 新增Claude风；专用主题包导入/预览/应用/删除、教程、AI提示词、示例包导出 | 个性化外观与业务数据分离，继续使用原有玻璃 |

没有恢复用户撤回的整页淡入或横移；`Glass.kt`、`LiquidRefraction.kt`、`NavigationPhysics.kt` 与本轮开始的备份逐字节一致。主题不得替换玻璃实现或导航物理。

## 真实操作边界

本轮沿用用户对帖子 `<redacted-id>` 的反复点赞并最终取消的授权。除该帖外，没有授权测试真实评论、关注、签到、删帖、资料保存、云收藏写入或新帖发布。实现这些按钮及确认流程与执行真实测试是两件事。

原生编辑器图片只在明确确认发布后上传；草稿按账号保存在本机，失败保留。提交之后无法确认结果时阻止自动重发，要求先核对我的帖子。图片上传与新帖协议尚未经过真实发布验收，不标为已验证可用。

已发布主帖的编辑继续通过原帖管理入口处理，原生编辑协议和服务端权限规则尚未补齐；没有将“删除后重发”冒充编辑。

## 持续缺口

原版差异清单的全量范围仍然有效。私信/群聊、点赞历史、头像/星座修改、完整的历史帖原生编辑、视频/语音/投票等发布类型、推送与高级社区管理仍需继续接入。关注动态已按官方 Userlike.DataRes 的 thread_info → ConcernData.thread_list 格式修正，本账号返回空数组；非空条目、混合动态及分页仍待样本验收。不会使用关注吧帖子替代它。消息空态不代表消息体系已全部完成。

本轮不宣称已完成完整官方客户端替代，也不计算未经定义的完成百分比。

## 字体与主题包

- 字体内置系统默认、思源黑体（Noto Sans SC）、霞鹜文楷轻便版、站酷小薇体，并提供“跟随主题”。手动字体选择覆盖主题推荐字体，独立于字号。字体文件未经修改，OFL原文与来源/SHA-256保存在 `app/src/main/assets/font_licenses/`，应用字体页也能查看授权。
- Claude风采用暖纸、墨灰和陶土强调，支持浅深色以及独立自定义色；不引入Claude服务或标志。主题选择改为纵向完整行，适配三种风格与大字号。
- `.h2theme` 使用版本头加单文件ZIP，限定32KB JSON、256KB包、20个本机主题。导入先预览，再保存/应用；相同id不会静默覆盖。禁止额外文件、路径、脚本、外链与字体载荷；不解压到任意路径。格式是专用容器，未加密，不能宣称绝对只被本软件读取。
- 应用内入口为“我的 → 设置 → 导入与管理主题 → 制作教程与 AI 提示词”，提供复制提示词与导出示例。教程、提示词与解析器使用同一v1规格；`examples/paper-sky.h2theme` 为按提示词生成的实际可导入示例，已纳入JUnit检查。
- 自制主题调整浅深配色、强调色、字体与信息流卡片样式；不执行代码，不改变百度数据来源、业务入口、玻璃效果和导航手势。浅深背景限制与自动文字对比度校正见应用内教程。

# 0.8.1-dev.1 个人内容管理

2026-11-22，versionCode 42。按[路线图](roadmap-1.0.0.md)推进个人内容管理的首批功能。

- 「我的 → 浏览历史 → 管理」支持按条勾选、全选、取消全选和删除确认。取消确认保留勾选，页面返回先退出多选。删除一次写入历史，只移除所选记录。原有单项移除和清空入口仍可用。
- 「我的帖子」按帖子 ID 去重，「我的评论」按帖子 ID 和评论 ID 去重。同一帖下的不同评论各自保留。遇到完全重复的中间页时，只要服务端仍有下一页，就可继续加载。加载下一页失败后保留已读列表，重试从失败页继续。
- 点击有有效 ID 的评论继续使用原有评论定位。服务端分组中的子评论若缺少独立 ID，不继承外层记录的 ID，避免定位或删除到其他评论。这类评论仍可打开原帖。

## 0.8.1-dev.3 复验

2026-11-22，versionCode 44。对同一个目标，贴吧的定位接口建议第 2 页，但第 1 页的 5 楼预览包含目标评论 ID。「我的评论」现在优先选择含有准确 ID 的页面。仅返回候选父楼时，应用读取该楼的回复并核对 ID，确认后才打开对应楼中楼。

`tools/build.py release` 和 `tools/build.py check` 通过。APK v2 签名通过，291 项测试通过，Lint 0 错误。设备截图在 `.tools/checks/081-dev2-device/03-dev3-nested.png` 和 `04-dev3-direct.png`。账号的两张个人内容列表仍只有一页，真实跨页和弱网分页重试尚未覆盖。

# 0.6.3 悬浮播放器与长按倍速

2026-11-14，versionCode20。按用户选定的 B 悬浮 Orbit 方案实现原生播放器，更新独立 HTML 交互稿。

| Before | After | Why |
| --- | --- | --- |
| 中央播放、底部进度/倍速/静音、顶部全屏 | 底部单一液态玻璃浮岛集中播放、后退5秒、进度、倍速、静音和唯一全屏；竖屏标题在上方 | 采用 B 方案，减少画面中央遮挡并便于单手操作 |

| 140/120ms控件显隐，部分按钮不重置计时 | 260/240ms显隐、所有实际操作重新开始2.5秒计时 | 减少突然消失，操作后有完整停留时间 |

## 实现

`VideoAttachment.kt` 复用原 GlassPanel/LiquidRefraction，只在单个浮岛采样实际视频背景；内部按钮有轻量圆形底，不逐个嵌套采样。宽度不足时控制分两行，使用现有 LocalTouchTarget 保留至少48dp物理触控；倍速按钮固定触控大小并缩减内边距，避免极端界面/字号挤压整行。原视频保持 fit 显示，不强制裁剪。原旋转恢复、系统返回、错误重试、后台暂停保留。

画面左右各35%采用系统长按识别，中间不加速。只有播放中可开始临时2倍速，不会因为暂停状态的长按而开始播放。`VideoHoldSpeed` 记录按下前实际速度，重复开始不会覆盖快照；松手、取消、多指、停止播放、失败、生命周期暂停和销毁均进行幂等恢复，不把临时值写入用户菜单。长按隐藏控制层并显示小型玻璃提示，松手恢复控制。TalkBack触摸探索禁用画面长按，仍可通过菜单选择2倍速；语义提供播放/暂停动作。

控制层进入显示，播放无操作2.5秒隐藏，单击显隐。暂停、缓冲、错误、进度拖动、倍速菜单及控制区键盘焦点阻止自动收起。关闭动画时显隐不作过渡；图片、页面和底栏原有动效未改。

## 从原仓库采用的原则

1. 每个动画都应有用途，例如解释状态、建立空间关系或反馈操作。高频动作应更快，必要时直接切换。
2. 动效跟随触发位置和手势方向，入场与退出分别设计；手指按住时直接跟随位置，不用弹簧拖慢追踪。松手后参考速度和距离完成运动，并支持中途再次抓住。
3. 按压、展开等状态变化保持同一元素的连续性，避免内容突然消失后以另一份元素重新出现。
4. 优先通过位移、透明度和缩放表达变化，避免逐帧修改布局或使用大面积模糊。网页的合成层技巧不能直接等同于 Android 线程行为。
5. 悬停交互需要有触屏替代；可点击区域应是真实组件的一部分。图标需要语义标签，颜色不能作为唯一状态提示。
6. 支持减弱动效，检查快速操作、异步加载和页面离开后的状态恢复。

## 氢贴吧的具体实现约定

以下是本项目的设计选择，并非上游规定的一套固定主题。

### 阅读与信息层级

- 帖子卡片以标题、正文摘要、图片和作者信息组织层级；弱化次要统计信息，减少争抢注意力的装饰。
- 统一间距、字体层级、图标尺寸、圆角和颜色语义，通过 Compose 主题集中定义；具体数值在首轮原型中确定。
- 支持浅色与深色主题、中文长标题、用户大字体和足够的文字对比度。图片加载前预留合理空间，减少列表跳动。
- 从详情返回时恢复列表和阅读位置。加载、错误、空列表与分页结束都有明确表现。

### 动效取舍

0.2.0 按用户要求新增玻璃风格：悬浮导航和阅读操作栏使用局部背景采样模糊、半透明渐变、高光描边和轻阴影。正文仍以高可读性底色显示。Android 12 以下降级为半透明材质；“我的”提供增强效果开关，关闭后使用实色并减少自定义过渡。导航颜色过渡、卡片按压和收藏反馈用于解释状态，保留系统的动画时长控制，不添加列表逐条入场动画。本机已检查浅深色、材质开关和短时滚动，其他设备和长期表现仍待验证。

阅读字号明确为正文 16sp、评论 15sp、楼中楼 14sp；开启大字号时统一增加 3sp，分别为 19 / 18 / 17sp，链接采用与所在内容相同的字号层级。

0.3.0 按用户认可的 HTML 方向采用紧凑分隔列表和五项悬浮导航。“我的”仅有一处设置入口，主题色为任意六位色值；将用户色相映射到具有足够文字对比度的浅深色角色，极端黑/白/黄等也须可读。常用栏目采用 140 ms 短淡入淡出，次级页面采用 220 ms 轻微横移与淡入淡出；不添加列表逐条入场。按压与导航收放遵循减弱动效及系统动画开关。玻璃与动效可分别配置，关闭增强材质时亦减少自定义过渡。

| 修改前 | 修改后 | 原因 |
| --- | --- | --- |
| HTML“我的”页两处设置 | 原型与原生仅一处设置 | 避免重复入口 |
| 主题色固定 | 自定义色值、预览、校验、持久化 | 满足个性化要求并保证文字可读 |
| 栏目和页面直接替换 | 栏目短淡化、次级页面轻微定向过渡 | 衔接突变，避免拖慢高频切换 |
| 大圆角帖子卡片 | 连续分隔信息流，玻璃集中在悬浮操作层 | 提升讨论密度和阅读清晰度 |

| 操作 | 约定 |
| --- | --- |
| 刷列表、分页、刷新数据 | 不逐条播放卡片入场动画；保持滚动与位置稳定 |
| 点赞、收藏、切换常用栏目 | 立即反馈；高频操作使用平台反馈或直接切换，栏目切换不额外添加整页滑动 |
| 弹出菜单、底部面板 | 短促过渡，运动方向对应触发位置或面板边缘 |
| 页面与内容展开 | 用动效解释空间和状态变化，避免延迟点击后的响应 |
| 拖动面板、滑动返回 | 跟随手指，松手后根据速度和距离完成或取消 |
| 系统禁用或减弱动画 | 减少位移与缩放，保证所有功能仍然可用 |

按压反馈参考移动端规范的 100–150 ms；小菜单参考 150–250 ms。手势松手后的面板使用支持速度传递和中断的原生弹簧，页面导航优先沿用平台行为，不强行统一时长。大部分自定义 UI 过渡控制在 300 ms 内，特殊情况说明原因；不能为了满足时长而延迟用户操作。

自定义定时动效使用上游曲线：进入或退出参考控制点 `(0.23, 1, 0.32, 1)`，屏内移动或形变参考 `(0.77, 0, 0.175, 1)`。不要从零尺寸缩放入场；锚定菜单从触发点展开，居中模态框保持居中。将曲线和时长集中为主题参数；弹簧参数按 Compose 的物理模型适配，不能直接复制其他框架的配置对象。

### 触控、反馈与无障碍

- 本项目将可点击区域至少设为 48 dp；图标视觉尺寸可以更小。不要通过覆盖相邻控件的不可见层扩展触控范围。
- 工具提示、收藏、分享等操作不依赖鼠标悬停；弹层支持点击外部关闭和系统返回。
- 点赞、收藏先及时展示操作反馈，再按服务端结果确认或回退；失败时提供可理解的提示，避免重复提交。
- 发送评论有发送中、成功和失败重试状态；失败保留草稿，键盘不遮挡输入内容。
- 为仅有图标的按钮提供 TalkBack 描述；已点赞、已收藏、禁用等状态具有对应语义。
- 触觉反馈只用于必要的确认、吸附或操作结果，并遵循用户系统设置。

### Android 实现与性能

- 使用 Kotlin / Jetpack Compose，将上游 CSS、React、Motion 示例转化为原生行为，不直接引入网页实现。
- 帖子列表使用按需组合和稳定的项目标识；图片按目标尺寸加载与缓存，避免滚动中反复解码大图。
- 网络、解析和图片处理避免阻塞主线程。将频繁变化的动画状态限制在需要更新的组件内，减少不必要的重组和布局。
- 结合 Compose 的绘制与图层能力选择合适的动画 API；不假设使用某个 API 就自动获得流畅表现。
- 性能验收使用发布构建，在目标中低端真机上观察快速滚动、图片密集列表、连续开关面板和重复进入详情；结合帧耗时记录判断，不能仅依据模拟器或开发电脑体验下结论。

## 设计验收场景

- 极长中文、无空格链接、空正文、多图和图片加载失败。
- 浅色、深色、系统大字体、窄屏，以及状态栏、导航栏和键盘的遮挡。
- 首次加载、慢网、断网、分页失败、空列表与重试后恢复。
- 连续点赞、重复打开与关闭面板、动画中途返回和快速切换页面。
- 收藏或评论请求失败、草稿恢复、返回列表后位置保持。
- TalkBack、无障碍点击区域与关闭动画后的完整操作流程。

评审已有动效时，用“修改前 / 修改后 / 原因”表格列出问题，优先检查该动效是否应该存在，再检查参数、性能和细节。标明哪些结论来自代码、哪些经过视觉或真机验证；不要将未测试的表现写成已通过。

2026-11-11 已实现首版原生列表、详情、楼中楼、图片预览、本地收藏、阅读设置及官方网页入口，完成部分真机验证和公开读取接口验证。具体证据与未覆盖场景见 [真机验证记录](device-validation.md)；账号写操作、完整无障碍和中低端设备性能仍待验收，不能将以上整套场景视为全部通过。

### 用户身份信息

头像与徽章采用百度返回的图片；网络失败有名字或图标占位，并提供加载状态语义。姓名优先单行省略，等级、称号与徽章另起可换行的辅助信息，避免挤占正文或覆盖楼层、“楼主”等信息。不添加徽章入场动画。吧内角色与全站徽章分开使用；图片徽章不根据内部名称猜测荣誉或付费身份。

### 0.3.2 导航修订（取代 0.3.0 页面过渡约定）

按用户新要求取消整页淡入、横移过渡；页面直接切换并保留各页状态。动效集中于底部选中透镜：点击使用临界阻尼移动，拖动阶段直接映射横向距离，边界提供阻力，松手继承速度并以轻微回弹落位；快速反向操作可以中断。中间发帖为动作按钮，不作为滑动落点。

底栏使用胶囊轮廓与弱化主题染色的玻璃透镜，Android 13 及以上在采样背景层应用 AGSL 位移和轻微色散，图标、文字和触摸目标保持稳定；Android 12 使用模糊，更早版本或不支持 shader 的设备使用材质兜底。关闭增强效果显示实色；减弱动效取消弹性移动，手势拖动保留直接跟随。此为原生实现方向，不将参考视频的介绍当作实测性能。

### 可选映间 MARGIN 风格

用户指定参考 `jiuyang5354/bilibili-margin`。研究了仓库 README、浅深色截图、`01-base.css` 和排版/材质定义；本次本地快照 package.json 为 0.60.41。借鉴暖白/墨黑画布、编辑式标题、无衬线正文、等宽数字与时间、发丝边框、青蓝强调及弱雾背景，以原生 Compose 独立实现。没有把网页插件、外部素材、天气、热力图或其业务逻辑引入本应用。

| Before | After | Why |
| --- | --- | --- |
| 只有单一视觉风格 | 设置中选择经典 / 映间 MARGIN | 用户可选择参考风格并切回原外观 |
| 外观模式与主题色是仅有维度 | 风格、浅深模式、强调色分别保存；每种风格各自记住色值 | 切换风格不覆盖原有自定义色 |
| 信息流统一平铺 | 映间使用细线浅卡片、标题/正文/数字的字体分工与少量留白 | 建立阅读层级，保留所有已接入信息与操作 |
| 单色画布 | 映间增加低强度静态蓝雾；文字与控件保持实质对比度 | 参考仓库截图气质，避免为刷帖增加循环装饰动效 |

经典仍为升级后的默认选择；映间默认青蓝，可自定义。现有 `Glass.kt`、`LiquidRefraction.kt` 的折射、模糊、选中透镜与手势物理不因风格改变。效果开关和减弱动效继续独立生效，不恢复用户已撤回的整页过渡。浅深色、大字体、关闭玻璃与切回经典均需真机检查。

### 字体、字号与自制主题

字体选择属于外观偏好，与信息内容、账号数据和百度接口来源分离。提供系统默认、跟随主题及内置中文字体时，页面必须给出真实样本；手动字体优先于主题字体，系统缺字允许回退。字号和界面倍率分别调整，应用后才写入本机；最小值仍须保留可操作的触控区域，长中文与底部导航不能裁切。

自制主题包只携带数据，不执行脚本、不加载外部资源、不改变业务入口或百度数据来源。导入先解析和预览，再保存并应用；字段、颜色对比度、文件数量和大小均需校验，失败保留当前主题。主题包使用专用容器而非加密格式，产品文案不得声称绝对无法被其他工具读取。教程必须说明生成、导入、删除回退和字体优先级。

### 0.5 阅读与页面衔接（当前约定）

2026-11-12 用户重新明确要求页面衔接动画，取代0.3.2及后续段落中“撤回整页过渡”的历史约定。常用栏目140ms淡化，次级页面220ms淡化和小幅定向横移，退出120ms；遵循减弱动效和系统动画设置。用路由标识区分导航与数据更新，刷新/分页不触发整页动画，不添加列表逐条入场。

保留原液态玻璃、底栏透镜拖动、回弹和按压。播放器关闭/唯一全屏按钮、中央播放和底部控制胶囊复用玻璃；控件140ms显/120ms隐，播放2.5秒后隐藏，暂停/错误和触摸探索时保留。退出恢复原方向，后台暂停。

字体倍率50–150%，界面仍90–120%，视觉缩小不缩减真实点击区域。帖子收紧间距，区别正文与次要统计；列表移除关注，吧名放大为可点击主题色胶囊。搜索历史用小标签、默认4条、显式展开/收起。图片画质统一在设置，预览不重复放切换按钮。对照和边界见[0.5记录](iteration-050.md)。

早期追加（已由下方0.5.3连续滚动修正取代）：浏览首页标题与推荐/关注栏、吧页工具栏、逛吧标题与底栏共享同一收放决定，不各自猜测滑动方向。沿用38dp收起、20dp恢复阈值和路由切换恢复；顶部同时释放占位，反向滑动恢复操作入口。关闭自动收起后顶部常显；减弱动效时立即切换，底栏原动效及玻璃实现不改。最后追加项按用户要求不做实机验收。

### 0.5.1 加载与签到反馈

首次空内容加载只显示列表加载提示；保留内容刷新只显示顶部刷新控件；分页显示列表底部加载，避免同一任务双转圈。空列表仍可下拉重试，不通过禁用刷新手势解决视觉重复。一键签到用单条线性进度和文字计数，逐吧结果以文字区分成功、已签到、失败和待处理，不只依靠颜色。支持停止、明细、仅重试失败和继续未完成；不会为每个成功弹出模态框。选吧显示“吧”后缀，不改变真实接口吧名。对照见[0.5.1记录](iteration-051.md)。

### 0.5.2 个人主页

头像右侧分别显示关注/粉丝玻璃胶囊，数字优先、标签其次，点击打开真实关系列表。背景取百度资料中的主页背景，在下方渐变融入浅色白底或当前深色/主题底面。控制层与背景采样层分开，避免采样自身；不改变底部导航原有折射、手势与动效。背景缺失/失败采用主题渐变；大字号下控件自然增高、数值不挤压头像。对照见[0.5.2记录](iteration-052.md)。

### 0.5.3 设置滑条与图片预览

用户选择液态玻璃滑条用于字体/界面大小。保留原生Slider的手势、键盘、进度语义及至少48dp真实触控高度；视觉为细轨、玻璃胶囊，拖动位置直接跟手。轨道单独采样，不采样整个设置页或滑块自身；不以实色矩形覆盖页面渐变。关闭玻璃与减弱动效分别回退，底部导航原实现不改。

图片画质只在设置管理，预览移除画质、像素尺寸和缩放提示的常驻胶囊。缩放可通过既有手势和无障碍描述发现；错误/重试仍明确显示。新评论设计稿遵循正文优先、小配图和浅底楼中楼摘要，不将演示数据或本地交互当作真实功能已实装。

### 0.5.3 顶部栏滚动与界面倍率修订

顶部标题及推荐/关注栏作为完整内容随竖直滚动逐像素上移，回拉逐步露出，不再使用底栏的38/20dp阈值与AnimatedVisibility淡出/收缩。每页独立滚动状态，测量完整高度后裁剪移出区域；只消费实际用于顶栏的距离，剩余交给列表和下拉刷新，惯性仍走同一滚动链。减弱动效时保留直接操纵；关闭自动收起常显。底栏现有收放、玻璃与导航物理不改。

界面倍率70–120%连续调节，不量化为5%或1%档位；界面百分数只作四舍五入显示，保存浮点原值。字号仍50–150%、1%步进。保留预览/应用与旧偏好，最小界面倍率也保留至少48dp实际触控区域。

### 0.5.4 评论与图片流程

原生评论采用左头像右正文、次要元信息与回复/赞同行、小配图和浅底楼中楼摘要，摘要只使用现有响应，不为每楼额外请求。完整对话保留父楼与精确子回复对象；退出编辑器恢复对话及被中断的加载。用户提及仅在真实ID存在时可点击；属地与时间缺失不猜测。更多菜单承载复制和完整信息，保留正文空间。

图库左右翻页与放大拖动分工：原比例可翻页，放大时拖动看图，复位后继续翻页；提供按钮作为无障碍替代。控件沿用液态玻璃，画质只在设置。保存先读取服务端原文件，再由系统选择位置；不对预览位图重压缩，不新增常驻底部教程或装饰入场。实现与验证边界见[0.5.4记录](iteration-054.md)。

用户追加要求所有按钮和页面入口有气泡背景：图标圆形、短动作胶囊、长入口圆角气泡；浅深色及自制主题取当前色板，未选中项也有底，选中/禁用可辨认。保留48dp真实触控与原生按压、焦点、进度语义；常驻气泡使用轻渐变和高光边，避免列表中每个控件独立模糊。既有悬浮玻璃、透镜和导航物理继续保留，关闭增强材质回退实色。

0.5.5 修订：帖子卡片底部评论、点赞、收藏、分享四个动作统一等宽、等高胶囊背景及18dp图标；同一行以最高内容确定共同高度，保持至少48dp真实触控。评论与点赞保留计数，收藏与分享居中显示图标，不能因有无数字而切换成不同尺寸的背景。

0.5.5 图片预览修订：列表允许裁剪缩略图，打开后各画质均须读取完整构图。低/中档选完整图片地址，高档优先服务端原图，以解码上限区分预览精度；不能仅放大列表缓存。缺少完整来源时在预览内补读同帖详情，以图片标识匹配并保留完整签名；失败明确重试，用户可选择查看现有图片。画质仍统一在设置中选择。

### 0.5.6 菜单与消息

所有下拉菜单使用同一圆角外框（22dp）、内部气泡（14dp）及间距，避免默认矩形与气泡边缘冲突；保留主题配色、48dp触控和原生关闭行为。设置按六类和下级字体/主题/教程组织，所有现有偏好可达，系统返回逐级退出。

消息通知明确区分动作标题、原文和引用，回复动作为“回复我：”；进入回复先展示原帖上下文，再定位父楼或具体楼中楼，并允许读取前后页。表情内联于文字、随字号调整，不当作照片或额外计入图库。聊天页面必须明确原生读取、官方网页承接及尚未接入的收发范围，不以入口代替功能完成。详见[0.5.6记录](iteration-056.md)。

### 0.5.7 下载目录修订

图片下载点击后直接保存到系统`Download/HTieBa/`，自动建目录，不弹出目录或文件选择器。保留原始文件字节和真实扩展名，不按预览画质重新压缩；使用唯一文件名，避免覆盖用户文件。Android10及以上用MediaStore下载集合先写待完成文件、成功后发布，失败或取消清理；Android8/9先申请系统存储权限再写公共下载目录。下载按钮提供进行中、成功目录提示和失败重试反馈，沿用既有液态玻璃控件。此约定取代0.5.4“由系统选择位置”的图片保存流程。


### 0.5.8 当前修订

界面倍率扩展为50–150%连续调节，并提供50/75/100/125/150%常用档；取代此前70–120%范围，保留字号独立、预览后应用和实际触控尺寸。图片行必须先确定边界，不叠加互相冲突的高度与宽高比限制。根主题默认文字采用当前色板onBackground；照片上的玻璃及个人背景遮罩另做对比保护。

图片预览工具栏进入可见，单击图片隐藏，再单击显示，保留双击缩放与系统返回。“我的”根页底栏常驻；个人背景允许本机替换与恢复官方图，不上传更改账号。玻璃外框36/50dp、跳转气泡26dp、菜单外框30dp/内部22dp；圆形、胶囊保持原轮廓，菜单留白需匹配内外形状。

按用户新要求，主导航从140ms淡化改为200ms定向横移、短暂模糊和渐晕；次级页面原220ms衔接不变。模糊限5dp，底栏折射和选中透镜物理保留；关闭增强效果、减弱动效及系统动画关闭均回退，旧系统不模拟昂贵模糊。搜索/发帖输入先提供三种交互稿，选定后实装。


### 0.6.0 分层卡片输入

用户选定0.5.8设计稿中的“分层卡片”。原生搜索以独立玻璃输入层、紧凑历史卡片、按需组合的热榜分组组织内容；只有帖子/吧/用户三个真实搜索范围，不引入演示稿的假综合分类。输入与结果共用可滚动区域，窄宽度下搜索动作换行，键盘不能盖住编辑区域；清空、历史展开、链接直达、重试和分页继续可用。

发帖使用账号/发布吧、标题/正文、图片附件三个圆角层，标题与正文同卡以细线区分，辅助信息降级为小字。所有文字依当前主题，常驻卡片不单独分配背景模糊；既有液态玻璃、底栏透镜及转场不改。保持自动本机草稿、读取权限、图片上限、发送锁定、确认发布和不确定结果核对；不加入没有真实功能的表情/话题按钮。50–150%界面缩放仍保留至少48dp物理触控，内容高度随字号和长文增高。

### 0.6.3 播放器 B 方案

用户从三套播放器交互稿选定 B 悬浮 Orbit。底部单一液态玻璃浮岛承载时间/进度、播放或暂停、后退5秒、倍速、静音及唯一全屏入口，移除中央播放按钮和顶部重复的全屏位置。标题在竖屏浮岛上方、横屏顶部；不补造接口未提供的作者信息。浮岛复用 GlassPanel 的实际视频背景采样与折射，内部按钮只使用轻量背景；窄宽度和大倍率时分两行，保留至少48dp物理触控。

视频播放时，画面左侧35%或右侧35%长按使用系统长按阈值临时2倍速；松手、手势取消、多指介入、暂停/缓冲/失败、切后台及关闭都恢复按下前速度。长按不写入菜单倍速；暂停时长按不主动播放，中间区域长按不加速。长按期间隐藏控制层，顶部显示小型2倍速提示，松手后恢复控制并重新计时。

进入显示，播放且无操作2.5秒自动收起；单击画面显隐。暂停、错误、缓冲、拖动进度、倍速菜单打开、触摸探索或控制区键盘焦点期间不自动收起。所有按钮操作重置计时；控制显隐260/240ms，沿用项目EaseOut，系统关闭或减弱动画时即时反馈。横竖屏仍完整显示视频，不强制裁剪；退出方向恢复与后台暂停继续保留。此约定取代旧播放器140/120ms及中央播放布局，图片与其他页面动效不变。

### 0.6.6 播放进度细化

视频进度属于真实播放状态：可见且播放时按帧采样实际时钟，仅重绘进度，不为播放时间加入缓动追赶。暂停、缓冲和拖动优先准确反馈，隐藏控件后停止帧采样。时间标签下移靠近轨道但保留触控高度与圆角内留白；倍速菜单单独缩窄，保留全部档位、原生关闭、选中语义及48dp物理触控，文字放大时允许行高增长。B浮岛比例、位置与原有液态玻璃、显隐不改。

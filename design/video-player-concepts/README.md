# 视频播放器 · 三套可交互设计稿

2026-11-14。入口为 `index.html`，使用 Chrome / Edge 直接打开，无需联网或安装依赖。请保留整个文件夹，视频、海报、样式与脚本通过相对路径加载。本次没有修改 Android 代码、版本、APK，也没有操作手机。

## 三种方向

| 现有布局 | 新设计 | 目的与取舍 |
| --- | --- | --- |
| 中央播放 + 大块底部玻璃控制面板 | A 沉浸 Edge：底部细进度线、独立玻璃控件 | 接近 X 的画面优先布局，保留中央播放入口。控件分散，单手触达不如 B 集中 |
| 播放和常用操作分散在中央与底部 | B 悬浮 Orbit：底部单一玻璃浮岛，播放与快退靠左 | 常用控制集中，取消中央遮挡；浮岛比 A 占用更多底部画面 |
| 控件直接覆盖视频 | C 分层 Frame：独立画框、外置进度与控制、独立元信息 | 对画面遮挡最少，横屏移为右侧控制；可用视频面积比 A/B 小 |

保留玻璃的透明叠层、局部背景模糊、高光边缘和圆润触控面。HTML 是材质与布局表达，不等同于 Android 的真实背景采样和 AGSL 折射实现。

## 可试用交互

- 播放/暂停、实际视频进度拖动、五档倍速、静音/声音、唯一的全屏/退出全屏按钮。
- 播放中 2.5 秒自动隐藏；单击画面显隐；双击左右区域后退/快进 5 秒。
- 暂停、进度拖动、倍速菜单及键盘聚焦控件期间保留控制；关闭后可重新打开，切换方案保留当前播放进度。
- 竖屏/横屏设备与竖版/横版视频分别切换；完整显示原视频比例，不为了填满而裁掉画面。
- 浅深画布、减弱动画、按钮按压、可访问名称；预览区域支持空格、左右键、M、F，原生进度条支持键盘操作。
- Esc 在全屏下退出全屏；在预览内切换控件；倍速弹出层可用 Esc / 点击外部关闭。
- 页面切到后台暂停，媒体失败提供重试。全屏受浏览器能力及用户操作策略约束。

画面是 `scene.js` 原创程序绘制山水，`generate-media.cjs` 在本机生成两个真实 12 秒 WebM，包含轻微山风运动和极轻的合成环境音，默认静音。不使用用户手机录屏、账户数据或外部媒体。三个方案使用同一段素材，便于比较布局。

控件显/隐 260ms，按压 120ms，采用项目 `cubic-bezier(.23,1,.32,1)`，支持中途反转和 `prefers-reduced-motion`。视频内容自身的运动不受减弱界面动画设置影响。

## 验证

运行 `node design/video-player-concepts/validate.cjs`。脚本使用本机 Chrome 与已有 Playwright，无新增依赖。结果在 `validation.json`，截图在 `screenshots/`。

已验证：3 个方案 × 横竖设备 × 桌面/390px 手机宽度；无页面水平溢出，操作按钮在屏幕内；播放/暂停、自动收起、点击恢复、拖动进度、倍速、静音、全屏及退出、关闭及重新打开、两种视频源、浅深画布、减弱动效。浏览器控制台无脚本异常。

这些是浏览器交互验证，不代替原生实现后的 Android 真机性能、方向恢复及 TalkBack 验收。

## 选定 B 与长按补充

用户已选定 B 方案。入口默认打开 B，A/C 继续保留为对照。播放时长按画面左右35%区域500ms临时2倍速，松手恢复原来的菜单倍速；中间区域与暂停状态不触发。长按期间显示小型倍速提示并隐藏浮岛；松手重新显示，并从头计时2.5秒。取消指针、移出按压位置、多指介入、窗口失焦、暂停/结束/失败会清理临时倍速，不改变倍速菜单选择。

补充验证脚本 `validate-hold.cjs` 和结果 `hold-validation.json` 覆盖左右两侧、1.25/1.5恢复、松手不误触单击、取消、暂停/中央不触发、移动取消、倍速菜单保持及关闭后的重新隐藏、窗口失焦恢复。Android 原生使用系统长按阈值，具体交付见 `docs/iteration-063.md`。

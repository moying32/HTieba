# C 方案深化：私信与吧群

2026-11-14。用户已选定 C「紧凑对话流」，允许适当参考 Telegram 交互。本目录为选定方案的独立可交互设计稿；前轮三方案留在 `../chat-concepts/`，作为设计历史。

直接打开 `氢贴吧-私信与吧群-C方案深化.html`。桌面三屏对比，手机宽度切换会话列表 / 私信 / 群聊。

## 选定的设计

| 之前 | 现在 | 目的 |
| --- | --- | --- |
| 三种设计方向并列 | 固定 C 方案 | 统一后续原生实现依据 |
| 每条消息下独立回复按钮 | 左滑回复；长按 / 右键 / Shift+F10 打开操作菜单 | 减少重复控件，保留可访问的操作路径 |
| 引用仅展开文字弹层 | 点击引用定位并短暂高亮原消息 | 避免丢失讨论上下文 |
| 大块「继续上次讨论」卡片 | 置顶 / 最近分组，紧凑对话行 | 给更多会话留出空间 |
| 群内容入口较少 | 群资料统一容纳公告、成员、图片、帖子 | 聚合当前会话共享内容 |

收到的消息使用头像、姓名和正文排版，不额外套大气泡；自己发送的消息以柔和主题色底区分。玻璃集中在输入栏、导航、菜单和功能浮层；保留贴吧的吧身份、通知三入口和五项主导航。没有改成 Telegram 的品牌配色或复制其完整布局。

根据本轮浏览器三处批注，搜索框的可见玻璃底收至36px，分类胶囊与「查看更早消息」收至30px，空输入栏收至44px、发送圆钮视觉直径36px。真实交互区域仍至少48px，背景在各自控件内部绘制；多行输入和大字号按内容增高，不压缩文字或手势区域。

## 可操作流程

- 左滑消息引用：超过48px，或有效快速左滑后松手进入引用。手指按住时直接跟随；放开后快速弹簧收回。正常竖向滚动、取消和多指不触发回复。
- 长按430ms / 右键 / Shift+F10：回复、复制、本地收藏、选取。复制权限不可用时提供可选中文本。
- 引用携带原消息ID，点击定位；共享图片、帖子、本地收藏也支持定位回原消息。
- 会话搜索：仅搜索当前已加载消息，高亮关键词，上一个 / 下一个，无结果有明确提示。
- 长按菜单选取消息后可继续点选、复制多条或退出。
- 会话列表可筛全部 / 私信 / 吧群 / 未读；会话右侧更多提供置顶、免打扰、标为本地已读。
- 输入草稿随会话保留，列表显示草稿；发送完成回调不能清除随后输入的新草稿。回看旧消息时可用向下箭头回到最新。
- 私信 / 群资料的图片与帖子来自当前已加载的演示消息；群公告常驻轻条，成员集中在资料中。
- 图片预览、示例帖子分享、陌生人消息、空 / 失败状态、发送失败重试继续保留。

## 原生接入边界

这是设计与交互稿，不是已经接通的私信服务。全部消息、身份、未读与开关状态为本地演示；不会发出远程请求，不读取账号，不产生真实发送。数据与本地收藏随页面重载清空。

借鉴的是操作习惯；原生功能仍通过百度贴吧协议读取与提交。在线、输入中、已读回执、撤回、编辑、云端反应、实时推送等不添加虚构数据或成功反馈。资料、历史、附件类型及引用发送需依据真实接口能力逐项验证；无权限或不支持的动作需在原生层明确降级，不能仅凭设计稿视为实现完成。

原生后续需将长按 / 滑动回复映射为 Compose 手势与 TalkBack 操作；保证至少48dp物理点击区域，继承主题、字体、界面倍率、系统返回、键盘与减少动态效果设置。网页截图不能证明真机手感、真实收发或实时未读同步通过。

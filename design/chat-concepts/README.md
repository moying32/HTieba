# 私信与吧群 · 三套可交互设计稿

2026-11-14。为氢贴吧的原生私信和吧群接入先确定布局与交互，保留液态玻璃材质、贴吧社区身份及现有五项主导航。

打开 `氢贴吧-私信与吧群-三方案.html`，左侧切换 A / B / C。桌面同时预览会话列表、私信、群聊；窄屏通过「会话列表 / 私信对话 / 吧群聊天」切换。四份 HTML 均可离线直接打开，无第三方资源依赖。

| 方案 | 组织方式 | 对话样式 | 独立文件 |
| --- | --- | --- | --- |
| A 统一收件箱 | 私信与吧群合并，按最近活动排列；全部 / 私信 / 吧群筛选 | 左右对话气泡，群公告轻条，单行玻璃输入栏 | `方案A-统一收件箱.html` |
| B 双轨分区 | 私信 / 吧群分轨；私信常用联系人，吧群按所属吧分组 | 分层输入卡片，群身份卡与聊天 / 图片 / 群资料入口 | `方案B-双轨分区.html` |
| C 紧凑对话流 | 继续上次讨论 + 紧凑会话列表 | 收到的文字直接排版，发送消息用柔和底色区分；引用可展开上下文 | `方案C-紧凑对话流.html` |

## 可试用

- 搜索、筛选、切换会话和返回列表；搜索条件保留。
- 输入、表情、模拟发送、引用和取消引用；Ctrl/Cmd + Enter 发送。
- 「加载失败」状态下发送会保留失败消息，可点击重试。
- 演示图片和帖子分享、打开预览、查看更早消息。
- 点群名或右上角查看公告、示例成员、置顶和免打扰开关。
- 新建私信、陌生人消息与接受会话。
- 深色、大字号、空列表、失败、重试，以及系统减少动态效果设置。
- 弹层可点遮罩、关闭按钮或按 Esc 关闭，键盘焦点限制在弹层内并在关闭后恢复。

## 能力边界

所有头像、姓名、消息、人数、通知和开关状态均为本地演示。不会连接百度，不会读取账号、上传图片或产生真实互动；重载页面后演示状态清空。没有用模拟在线、已读或实时到达状态来表示已经接通服务。

原生版本当前的私信仍依赖网页；吧群已具备目录、资料及历史读取入口。完整私信收发、群内发送、未读同步及其他能力，需要后续依据百度接口逐项接入和验证。本稿不代表这些功能已完成。

## 实现与验证

源文件为 `index.html`、`style.css`、`app.js`；执行 `python design/chat-concepts/build_standalone.py` 重新生成独立稿。头像与图片为本地编写的 SVG，非下载素材。

浏览器验证：`node design/chat-concepts/validate.cjs`。结果见 `validation.json`，截图见 `screenshots/`。覆盖三方案的主要交互、1540px 桌面、390px / 320px 窄屏、浅深色、大字号和减少动态效果；检查无水平溢出、无 JavaScript 错误、无远程请求。

本轮没有进行物理手机验收，没有修改原生 Kotlin 源码或安装 APK。

# 氢贴吧 · 可交互 HTML 设计稿

2026-11-11 · Concept 01。设计目标来自用户明确提供的《要求补充.md》及本项目产品、设计规范。本次只交付设计稿，Android 版本和账号会话均未修改，手机验收保持暂停。

## 打开

直接用浏览器打开 **`氢贴吧-交互设计稿.html`**。这是打包后的单文件，样式、脚本、图标、插画全部内嵌，无需安装依赖或联网。推荐 Chrome / Edge。浏览器对本地文件存储的限制可能导致刷新后无法恢复草稿，正常情况下当前页面仍能操作。

源文件入口为 `index.html`。要以本地网页运行，在项目根目录执行：

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory design/prototype
```

打开 `http://127.0.0.1:8765/`。重新生成单文件：

```powershell
python design/prototype/build_standalone.py
```

宽屏提供左侧设计说明、中间手机预览、右侧审阅控制；窄屏呈现全屏应用预览。右侧控制用于审阅，属于设计稿工具，不是应用自身的信息架构。

## 可以操作的内容

| 入口 | 可检查的交互 |
| --- | --- |
| 刷帖 | 推荐/关注/热榜切换、继续浏览、帖子详情、作者主页、点赞、收藏、分享文字 |
| 搜索 | 热搜、历史、关键词提交、综合/帖子/吧/用户结果；示例词“摄影”“生活”“Minecraft” |
| 帖子 | 图文、放大插画、只看楼主、回复排序、楼层、楼中楼、本地文字回复 |
| 逛吧 | 关注吧列表、吧搜索、签到反馈、推荐、分类、排行、吧主页、全部/最新/精华 |
| 发帖 | 选吧、标题、正文、本地图片预览、视频附件状态、二选项投票、提及、表情、文字草稿、本地发布结果 |
| 消息 | 赞/回复/@、关联原帖、关注联系人、陌生人、群聊、本地聊天发送与清理 |
| 我的 | 编辑资料、自己的帖子和回复、关注/粉丝入口、收藏、点赞、历史、草稿 |
| 设置 | 浅/深/系统主题、玻璃开关、大字号、减少动效、滚动导航、消息/流量偏好、账号入口、缓存、关于与署名 |

正常刷帖时，向下滚动超过一定距离收起底部胶囊；反向滚动恢复。页面返回使用标题栏返回或 Esc；返回时恢复上页滚动位置。面板可点击外部、关闭按钮或按 Esc 关闭，并限制键盘焦点到面板内。

## 材质和动效

- 按 Emil 的频率与用途原则安排反馈：点击按压、选中透镜位置切换、面板展开与退出、胶囊收放。信息流不播放逐条入场动画。
- 玻璃来自透明渐变、背景模糊、饱和度、边缘高光、内部阴影，以及原创圆角矩形位移贴图。SVG 位移仅作用于导航背后的采样背景，不扭曲文字和点击区域。
- 背景采样滤镜因浏览器不同可能降级；普通毛玻璃和实色开关均保留。该 HTML 效果不是 Android 上的性能或材质验收结论。
- 支持 `prefers-reduced-motion`、键盘焦点、图标语义、触屏 hover 区分、安全区域与动态视口。
- 原生落地继续使用 Kotlin / Jetpack Compose；本稿不引入网页框架到 Android 客户端。

## 演示边界

所有帖子、账号、计数、联系人和通知均为示例。点赞、关注、发帖、评论、举报和私信不向贴吧发送请求；成功反馈明确说明为本地演示。搜索仅匹配少量示例数据，不是在线搜索。

文字草稿、示例发帖、收藏、点赞、历史、个人资料和部分开关在当前浏览器存储。图片使用本地 Blob，仅本次页面会话保留，草稿不会持久化图片；发布后只展示第一张图以检查图文结构。视频只演示附件添加/移除，不上传或播放。投票是选择反馈，账号入口只展示流程说明。通知与网络设置不修改系统设置，缓存数字为示例。

HTML 内没有完整平台业务实现；未制作完整群管理、资料头像裁剪或全部设置深层页面。正式客户端仍需真实 API、异常处理、持久化媒体和原生无障碍等实施及验收。

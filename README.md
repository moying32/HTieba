## 构建与真机运行

要求 Windows、Python、JDK 21，以及 Android SDK Platform 36 / Build Tools 35.0.0。最低支持 Android 8.0（API 26），目标 API 36。

```powershell
python tools/bootstrap.py
python tools/bootstrap.py --check
python tools/build.py release
python tools/device.py info
python tools/device.py install --release
python tools/device.py launch
```

发布测试包：`app/build/outputs/apk/release/app-release.apk`。启用 R8 和资源压缩，当前使用开发测试签名，正式分发前需要配置独立签名及版本管理。

其他命令：

```powershell
python tools/build.py app
python tools/build.py wrapper
python tools/build.py smoke
python tools/build.py check
python tools/device.py screenshot --name home
python tools/device.py inspect --name home
python tools/device.py logs
. .\tools\env.ps1
```

`app` 编译调试版；`smoke` 编译独立环境检查应用；`check` 运行主题对比度、头像/徽章解析、本地记录兼容性、互动响应与导航物理 JUnit 测试及发布版 Lint。测试通过 Unicode 命令参数启动 JUnit，规避 Windows 中文路径下 Gradle worker 参数文件的问题。两种业务构建都会验证 APK 签名。设备脚本要求恰好连接一台已授权手机，界面检查要求氢贴吧在前台且手机亮屏解锁。`logs` 在部分荣耀设备上可能返回加密内容，不能用它证明无异常。

依赖、构建缓存和截图存放在 `.tools/`。环境脚本只修改当前 PowerShell 终端。下载校验及工具来源记录在 `.tools/environment.json`。Gradle Wrapper 固定 8.13 和官方 SHA-256；生成 Wrapper 时跳过受当前网络影响的 HEAD 探测，运行时保留分发包校验。Google Maven 在当前网络下 TLS 连接失败，因此使用阿里云 Google Maven 镜像；Maven Central 和 Gradle 下载使用官方源。

- [真机验证记录](docs/device-validation.md)：测试设备、已通过项目和未覆盖场景。

## APK 分析环境

项目内包含 Gradle 8.13、JADX 1.5.6 和独立虚拟环境中的 mitmproxy 12.3.1。

```powershell
. .\tools\env.ps1
adb devices -l
jadx --version
jadx -d .tools/decompiled apks/tieba.apk
mitmweb --set confdir=.tools/mitmproxy --listen-host 127.0.0.1 --listen-port 8080 --web-host 127.0.0.1
```

`apks/`、`captures/` 和 `.tools/` 均排除版本管理。本次读取了已安装官方客户端的 APK，没有复制其账号或私有应用数据，也没有向手机安装抓包证书、配置代理或修改官方客户端。

# 自制氢贴吧主题

1. 在本页复制 AI 提示词，在最后补充想要的配色和气质。
2. 将提示词交给支持生成文件的 AI，下载它生成的 `.h2theme` 文件。只有文本能力的 AI 可以生成 theme.json 和 Python 打包脚本，再在电脑执行脚本。
3. 打开「我的 → 设置 → 导入与管理主题 → 导入主题包」，从系统文件选择器选择下载的文件。
4. 查看浅色、深色预览、作者和字体，确认后点「导入并应用」。导入失败会显示具体原因，原主题保持不变。
5. 在管理页切换或删除主题。选择经典、映间、Claude 风可回到内置主题。删除正在使用的主题会回到此前的内置风格。

主题可设置浅深配色、强调色、内置字体、帖子是否使用卡片、卡片圆角。字号、界面大小、液态玻璃、减弱动效仍由你单独设置；主题不能改变账号数据、推荐来源、功能入口或导航手势。字体选为「跟随主题」时采用主题字体，选择其他字体后以你的选择为准。

`.h2theme` 是本软件识别的专用容器，并非给任意应用安装的通用主题。它没有加密；了解规范的工具仍能检查内容，不能保证绝对只有本软件读取。主题不包含脚本、网页、外链、图片或外部字体，导入过程不会上传文件。

默认配色会经过可读性调整；过浅的文字或强调色可能被加深，深色下则可能被提亮。不要将 AI 的预览图当作真实安装效果，请以应用预览为准。

## 文件规范 v1

最大文件 256 KB。开头是 ASCII `HYDROGEN-THEME/1` 后接一个 LF 换行字节，再接 ZIP 数据。ZIP 根目录只有 UTF-8 `theme.json`，不含 BOM、文件夹、多余文件，JSON 解压后最大 32 KB。不接受把普通 ZIP 直接改后缀。

固定字段：format 为 hydrogen-tieba-theme，schemaVersion 是整数 1，target 为 dev.hydrogen.tieba。id 是小写字母起头、只含小写字母/数字/短横线的 1–48 位标识；相同 id 不覆盖，更新前先删除旧版或换新 id。name 1–40 字，author 1–60 字，description 0–160 字，均为单行。

accent 使用 #RRGGBB。font 只能是 system、noto-sans-sc、wenkai、xiaowei。layout.cards 为布尔值，layout.cornerRadius 为 0–28 整数 dp。light 与 dark 都必须包含 background、surface、text、muted、border 五个 #RRGGBB 色值。其他字段会被拒绝。

浅色 background 和 surface 的 WCAG 相对亮度须 ≥0.55；深色两项须 ≤0.12，避免同一模式混用明暗相反的文字背景。文字和强调色在应用中会调整至至少 4.5:1 对比度。border 仅用于非文字分隔。

最多保存 20 款自制主题。主题仅保存在本机，删除本应用后会被清除；保留原主题文件可再次导入。字体授权可在「更换字体 → 字体与授权」查看。

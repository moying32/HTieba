    <title>0.7.6 HTieba氢贴吧</title>
    <content type="html">&lt;h2&gt;HTieba 氢贴吧 0.7.6&lt;/h2&gt;
&lt;p&gt;Android 原生贴吧客户端开发预览版。本次上传的是已留档的 &lt;strong&gt;0.7.6 原安装包&lt;/strong&gt;，没有重新构建。&lt;/p&gt;
&lt;h3&gt;本版更新&lt;/h3&gt;
&lt;ul&gt;
&lt;li&gt;发帖选吧支持搜索候选吧、点击填入，以及已关注吧快捷选择。&lt;/li&gt;
&lt;li&gt;选吧搜索加入 300ms 防抖，补充加载、失败重试、分页与过期请求处理。&lt;/li&gt;
&lt;li&gt;选择吧仅更新本地发帖草稿，不会自动发布帖子。&lt;/li&gt;
&lt;/ul&gt;
&lt;h3&gt;安装&lt;/h3&gt;
&lt;p&gt;下载附件 &lt;strong&gt;HTieBa-0.7.6.apk&lt;/strong&gt;，在 Android 8.0 / API 26 或更高版本安装。版本号 0.7.6，内部版本号 30，包名 &lt;code&gt;dev.hydrogen.tieba&lt;/code&gt;。&lt;/p&gt;
&lt;p&gt;APK 使用现有开发测试签名，v2 验签通过，并与 0.7.5 证书一致。仍为开发预览版，功能及稳定性尚未完整验收。&lt;/p&gt;
&lt;h3&gt;已知限制&lt;/h3&gt;
&lt;ul&gt;
&lt;li&gt;此安装包仍包含群消息 type 81、目标资料错误 220012 和群管理输入法返回等已记录问题。&lt;/li&gt;
&lt;li&gt;群加入、发送、撤回、屏蔽及取消屏蔽等写操作仍待真实验收；媒体发布、完整聊天和后台通知仍在开发。&lt;/li&gt;
&lt;li&gt;旧私信鉴权链路仍存在未使用 HTTPS 的已知限制。&lt;/li&gt;
&lt;/ul&gt;
&lt;h3&gt;源码与验证说明&lt;/h3&gt;
&lt;p&gt;本 APK 为 2026-11-15 留档产物；GitHub 标签指向本次发布时已托管的源码快照（&lt;code&gt;1f690a20fc1276a3beca92b8becdd5978ce558c6&lt;/code&gt;）。该快照中 ChatApi、ChatController 和 ChatProtocolTest 已有后续修改，&lt;strong&gt;不等同于此 APK 的精确构建源码&lt;/strong&gt;。GitHub 自动生成的 Source code 归档也不代表此安装包可逐字节复现。&lt;/p&gt;
